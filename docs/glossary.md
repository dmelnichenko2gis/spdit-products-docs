# Глоссарий

Раздел содержит единые определения терминов, которые используются в продуктах СПДиТ.

!!! info "Как пользоваться глоссарием"
    Термины сгруппированы по темам. Раскройте нужный блок, чтобы посмотреть определения.

---

<details markdown="1" open>
<summary><strong>Базы данных</strong></summary>

| Термин | Определение |
|---|---|
| База данных | Организованная, структурированная совокупность связанных данных, хранящаяся в электронном виде, например в форматах Excel, CSV или в СУБД. |
| Выборка организаций | Совокупность данных об организациях, содержащихся в базе данных и сформированная по заданным пользователем параметрам, включая выбранные рубрики и категории справочной информации. |
| Стандартный набор данных | Фиксированный набор данных, который должен присутствовать в базе для обеспечения её корректной работы и единообразия. |

</details>

---

### Классификация рубрик

Рубрики делятся на три уровня.

| Уровень | Название | Описание |
|---|---|---|
| 1 уровень | Рубрика 1-го уровня / категория | Обобщающая рубрика для множества других рубрик с одной тематикой. Включает рубрики 2-го и 3-го уровней. |
| 2 уровень | Рубрика 2-го уровня | Подкатегория внутри основной рубрики 1-го уровня, уточняющая и детализирующая её содержание. Может включать несколько рубрик 3-го уровня. |
| 3 уровень | Рубрика 3-го уровня | Самая узкая классификация рубрик справочника, объединяющая объекты, товары, услуги или материалы по общему признаку или направлению деятельности. Является базовым уровнем группировки данных. |
