# Вектор. Формат поставки

## Описание

Векторные данные могут поставляться в геоформатах, в виде пространственной базы данных или через картографические сервисы.

## Основные форматы

| Формат | Тип | Назначение |
|---|---|---|
| GeoPackage | Геоформат | Дополнительный формат поставки |
| Shapefile | Геоформат | Основной формат поставки |
| GeoJSON | Геоформат | Веб-карты и API |
| PostGIS | База данных | Загрузка в пространственную БД |
