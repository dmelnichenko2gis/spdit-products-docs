## :material-database: Наборы данных

Раздел описывает основные и дополнительные атрибуты организаций,
используемые для идентификации, адресации и геопривязки.

=== "Основные атрибуты"

    Базовый набор полей, доступный во всех выгрузках.

    | Описание | Атрибут | Пример | Комментарий
    |---|---|---|---|
    | Название организации | `FirmName` | Мелодия здоровья, аптека| Полное отображаемое название организации. |
    | ID фирмы | `FirmId`| 141274359270291 | Уникальный идентификатор организации. |
    | ID филиала | `FilialId`| 141265769628406 | Уникальный идентификатор филиала. |
    | Количество филиалов | `FilialsCnt`| 12 | Общее число филиалов организации. |
    | Субъект РФ | `SubjectFederation` | Новосибирская область | Регион Российской Федерации. |
    | Муниципальный район / округ | `DistrictRegion` | Новосибирский район | Район внутри субъекта. |
    | Город || `CityName` | Новосибирск | Населённый пункт. |
    | Район города | `DistrictName` | Центральный | Административный район города. |
    | Улица | `StreetName` | Красный проспект | Основная улица адреса. |
    | Номер дома | `HouseNumber` | 28 | Дом, корпус или строение. |
    | Почтовый индекс | `HouseIndex` | 630099 | Индекс здания.|
    | Этаж | `FloorFirm` | 1 | Этаж размещения организации. |
    | Офис / помещение | `Office` | пом. 4 | Номер кабинета или помещения. |
