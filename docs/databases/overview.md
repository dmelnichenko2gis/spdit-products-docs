## :material-lightbulb-on: Сценарии использования

| Сценарий | Что решает | Результат |
|---|---|---|
| 📈 **Аналитика** | Расчёт показателей, агрегация, построение отчётов | Дашборды, метрики, отчёты |
| 🔌 **Интеграция** | Передача данных в другие системы | API, выгрузки, синхронизация |
| ✅ **Проверка качества** | Поиск дублей, пустых значений, некорректных связей | Чистые витрины данных |
| 🕒 **Хранение истории** | Сохранение изменений по объектам и справочникам | Журналы версий, аудит |
| 📦 **Формирование поставок** | Подготовка CSV / XLSX-выгрузок | Готовые файлы для клиентов |

??? tip "📈 Аналитика — подробнее"
    Базы данных используются для построения аналитических витрин и расчёта бизнес-метрик.

    **Типовые задачи:**

    - количество организаций по городам и рубрикам;
    - динамика появления и закрытия организаций;
    - распределение бизнеса по территориям;
    - топ-рубрик в выбранном регионе.

??? tip "🔌 Интеграция — подробнее"
    Передача структурированных данных во внешние и внутренние системы.

    **Типовые задачи:**

    - подключение к BI (Tableau, Power BI, Yandex DataLens);
    - обогащение CRM и ERP-систем;
    - синхронизация со справочниками клиентов;
    - подготовка датасетов для ML-моделей.

??? tip "✅ Проверка качества — подробнее"
    Контроль целостности и достоверности данных перед поставкой.

    **Типовые задачи:**

    - поиск дублей организаций и адресов;
    - проверка обязательных полей на пустоту;
    - валидация связей между сущностями;
    - сверка с эталонными справочниками.

??? tip "🕒 Хранение истории — подробнее"
    Сохранение состояния данных на разные моменты времени.

    **Типовые задачи:**

    - отслеживание переименований и переездов организаций;
    - анализ изменений за период;
    - восстановление прошлых состояний для аудита;
    - сравнение версий справочников.

??? tip "📦 Формирование поставок — подробнее"
    Регулярная выгрузка данных в согласованных форматах.

    **Типовые задачи:**

    - генерация CSV / XLSX по расписанию;
    - подготовка тематических витрин;
    - адаптация структуры под клиента;
    - контроль соответствия SLA.

## :material-help-circle: FAQ

??? question "В каком формате поставляются данные?"
    Основные форматы — **CSV** и **XLSX**. Состав полей и кодировка согласуются индивидуально.

??? question "Какие данные входят в стандартный набор?"
    20 базовых атрибутов: название, ID, адрес, телефоны, часы работы, способы оплаты и др. Полный список — на странице [Модель данных](data-model.md).

??? question "Можно ли получить расширенные атрибуты?"
    Да, доступно 40+ дополнительных полей: координаты, юридические данные, рейтинг, ближайшая инфраструктура и др. Состав зависит от тарифа.

??? question "Что такое рубрика и ее уровни?"
    Рубрика — это единица классификации, объединяющая объекты по общему признаку или тематике. Используемые в продуктах рубрики ежемесячно обновляются в соответсвии с рубрикатором.
    Классификация уровней рубрик на странице [Глоссарий](https://spdit-products-docs-bd6ac0.gitlab-pages.2gis.io/glossary/).
