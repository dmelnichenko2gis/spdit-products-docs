# Базы данных. Формат поставки

## Описание

Раздел описывает форматы, в которых базы данных могут передаваться пользователям и внешним системам.

## Основные форматы поставки

| Формат | Тип | Назначение |
|---|---|---|
| CSV | Табличный | Универсальная выгрузка для анализа |
| XLSX | Табличный | Удобная поставка для пользователей |
