## :material-compare: Сравнительная таблица продуктов

<div class="spdit-section-table" markdown="1">

| Критерий | Базы данных | Адресный план | Вектор |
|---|---|---|---|
| **Тип данных** | Табличные | Адресные, табличные, пространственные | Пространственные |
| **Основная сущность** | Запись в таблице | Адресный объект | Геометрический объект |
| **Геометрия** | Не всегда | Может быть точка или полигон | Обязательна |
| **Основные форматы** | CSV, XLSX | CSV, GeoJSON, XLSX | GeoPackage, SHP, GeoJSON |
| **Использование в ГИС** | Да, при наличии координат | Да, при наличии координат | Да |
| **Типовое применение** | Аналитика, интеграция, хранение | Поиск и проверка адресов | Карты, ГИС, пространственный анализ |
| **Зависимость от справочников** | Высокая | Высокая | Средняя / высокая |

## :material-lightbulb-on: Когда использовать продукт

<div class="spdit-section-table" markdown="1">

| Задача | Рекомендуемый продукт | Почему |
|---|---|---|
| Нужно хранить и анализировать записи | **Базы данных** | Данные представлены в табличном виде и удобны для отчётов, BI и интеграций. |
| Нужно искать и проверять адреса | **Адресный план** | Содержит адресные объекты, иерархию территорий и адресные атрибуты. |
| Нужно отображать объекты на карте | **Вектор** | Содержит геометрию объектов и подходит для картографического отображения. |
| Нужно связать адрес с координатой | **Адресный план + Вектор** | Адресный план даёт адресную структуру, Вектор — пространственное представление. |
| Нужно построить отчётность | **Базы данных** | Табличная структура удобна для агрегаций, фильтрации и расчёта показателей. |
| Нужно провести пространственный анализ | **Вектор** | Позволяет работать с геометрией, слоями, пересечениями и расстояниями. |

</div>
