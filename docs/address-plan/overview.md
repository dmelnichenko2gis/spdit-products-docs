!!! info "Что такое адресный объект"
    **Адресный объект** — элемент адресной иерархии (регион, город, улица, дом, помещение), обладающий уникальным идентификатором, набором атрибутов и геопривязкой. Адресный план объединяет все объекты в единую структурированную базу.

## :material-lightbulb-on: Сценарии использования

| Сценарий | Что решает | Результат |
|---|---|---|
| 🔍 **Поиск адреса** | Поиск по полному или частичному запросу | Список совпадений с метаданными |
| 🧹 **Нормализация** | Приведение адресов к единому виду | Стандартизированные адресные строки |
| ✅ **Проверка адреса** | Контроль существования объекта | Подтверждение или ошибка валидации |
| 📍 **Геокодирование** | Получение координат по адресу | Точка с указанием точности |
| 🔄 **Обратное геокодирование** | Получение адреса по координате | Ближайший адресный объект |
| 🌳 **Адресная иерархия** | Определение родителей и потомков | Полная цепочка от региона до помещения |

??? tip "🔍 Поиск адреса — подробнее"
    Поиск адресных объектов по введённой строке с поддержкой неполного ввода и опечаток.

    **Типовые задачи:**

    - подсказки при вводе адреса в формах;
    - поиск зданий и помещений по части адреса;
    - подбор адреса при отсутствии полной информации;
    - поиск с учётом синонимов и исторических названий.

??? tip "🧹 Нормализация — подробнее"
    Преобразование произвольных адресных строк в стандартизированный формат с разделением на компоненты.

    **Типовые задачи:**

    - очистка адресных полей в клиентских CRM;
    - приведение разнородных источников к единому виду;
    - стандартизация сокращений (ул./улица, д./дом);
    - подготовка данных для последующей загрузки.

??? tip "✅ Проверка адреса — подробнее"
    Валидация адреса на этапе ввода или загрузки данных.

    **Типовые задачи:**

    - проверка существования объекта в справочнике;
    - контроль корректности иерархии (улица в указанном городе);
    - выявление недопустимых комбинаций компонентов;
    - формирование сообщений об ошибках для пользователя.

??? tip "📍 Геокодирование — подробнее"
    Определение географических координат для заданного адреса.

    **Типовые задачи:**

    - отображение адресов на карте;
    - построение маршрутов от точки доставки;
    - кластеризация клиентов по территориям;
    - подготовка данных для пространственного анализа.

??? tip "🔄 Обратное геокодирование — подробнее"
    Определение ближайшего адресного объекта по заданным координатам.

    **Типовые задачи:**

    - определение адреса по GPS-точке;
    - привязка фотофиксации к адресу;
    - сопоставление данных с координатами адресным объектам;
    - построение отчётов по точкам интереса.

??? tip "🌳 Адресная иерархия — подробнее"
    Получение полной цепочки адресной иерархии.

    **Типовые задачи:**

    - фильтрация объектов по уровню (город, район, улица);
    - анализ распределения данных по территориям;
    - формирование отчётов с группировкой по уровням.

## :material-help-circle: FAQ

??? question "Какие уровни адресной иерархии поддерживаются?"
    Полная цепочка от субъекта РФ до помещения: **регион → район → город → населённый пункт → улица → дом → корпус → строение → помещение**. Не все уровни обязательны — структура зависит от конкретного адреса.

??? question "В каком формате поставляются данные?"
    Основные форматы — **CSV** и **XLSX**, а также выгрузки в форматах ГИС (`SHP`, `GeoJSON`) при необходимости геопривязки. Состав полей согласуется индивидуально.

??? question "Есть ли координаты для всех адресных объектов?"
    Координаты предоставляются для зданий и помещений с указанием точности привязки. Для административных уровней (регион, район) — координаты центроидов.

??? question "Как часто обновляются данные?"
    Периодичность зависит от условий поставки — от еженедельной до ежемесячной. Источник данных — актуальный Городской Информационный Справочник 2ГИС.

??? question "Можно ли использовать адресный план для геокодирования?"
    Да, продукт содержит координаты для адресных объектов, что позволяет выполнять как прямое (адрес → координаты), так и обратное (координаты → адрес) геокодирование.

??? question "Как связаны адресный план и базы данных организаций?"
    Связь осуществляется через идентификатор здания `StableId`. По нему можно получить все организации, расположенные по конкретному адресу, и наоборот — определить адрес для записи об организации.
