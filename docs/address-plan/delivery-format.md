# Адресный план. Формат поставки

## Описание

Адресный план может поставляться в табличном или пространственном виде.

## Основные форматы

| Формат | Тип | Назначение |
|---|---|---|
| CSV | Табличный | Массовая выгрузка адресных объектов |
| XLSX | Табличный | Удобный пользовательский формат |
| GeoJSON | Геоформат | Адресные точки и геометрия |
| GeoPackage | Геоформат | Поставка адресов для ГИС |
