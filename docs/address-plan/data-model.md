!!! info "Что описывает модель данных"
    Модель данных адресного плана описывает **адресные объекты**, их **уровни иерархии**, **атрибуты**, **связи** и **координатную информацию**. Используется для нормализации адресов, геокодирования, аналитики и интеграции с другими продуктами СПДиТ.

## :material-database: Наборы данных

Раздел описывает основные и дополнительные атрибуты адресного плана, которые используются для описания территорий, адресных объектов, зданий и связанных характеристик.

=== "Основные атрибуты"

    Базовый набор полей, доступный во всех выгрузках адресного плана.

    | Описание | Атрибут | Пример | Комментарий |
    |---|---|---|---|
    | Проект | `Проект` | Москва | Название проекта, территории или набора данных, к которому относится объект. |
    | Субъект | `Субъект федерации` | Москва город федерального значения | Регион РФ, в котором расположен объект. |
    | Район субъекта | `Район области` | — | Район внутри субъекта. Для городов федерального значения может быть пустым. |
    | Город | `Город` | Москва | Населённый пункт. |
    | Район города | `Район` | Лианозово | Район или внутригородская территория. |
    | Почтовый индекс | `Индекс` | 127572 | Индекс здания. |
    | Улица | `Улица1` | Абрамцевская | Основная улица адреса. |
    | Дом | `Дом1` | 11 к2 | Номер дома, корпуса или строения. |
    | Этажность | `Этажность` | 12 | Количество этажей здания. |
    | Назначение | `Назначение` | Жилой дом | Тип объекта по классификатору. |
    | Количество организаций | `Количество организаций` | 3 | Число организаций в здании. Используется для геомаркетинга. |
    | Застройщики | `Застройщики` | — | Информация о застройщике, если доступна. |
    | Название слоя | `Название слоя` | Жилые дома | Слой карты, к которому относится объект. |

=== "Дополнительные атрибуты"

    Расширенный набор полей, подключаемый по запросу или по тарифу.

    | Описание | Атрибут | Пример | Комментарий |
    |---|---|---|---|
    | Количество подъездов | `Количество подъездов` | 3 | Число подъездов. |
    | Количество квартир | `Количество квартир` | 143 | Используется для оценки жилого фонда. |
    | Этажность компонент | `Высота компонент здания` | 36 | Высота отдельных частей здания. |
    | Материал стен | `Материал` | Панель | Полезно для систем связи и безопасности. |
    | Этажность максимальная | `Этажность максимальная` | 12 | Хранится отдельно, если отличается от общей. |
    | Обслуживающие организации | `Обслуживающие организации` | — | УК, ТСЖ, ЖЭУ. |
    | Ближайшая остановка | `Ближайшая остановка` | Исток | Название остановки общественного транспорта. |
    | Расстояние до остановки | `Расстояние до ближайшей остановки` | 330 | В метрах. |
    | Станция метро | `Станция метро` | Алтуфьево | Ближайшая станция. |
    | Расстояние до метро | `Расстояние до метро` | 1500 | В метрах. |
    | Провайдеры | `Провайдер` | Ростелеком для бизнеса \| Datiks \| Сибтелеком | Список провайдеров. Значения через `|`. |
